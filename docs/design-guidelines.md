# Design Guidelines

This document records design decisions that have been agreed upon. It should describe decisions, not ideas under consideration.

## Purpose

This document defines the visual identity and design principles of Daily Turtle.

---

# Project Identity

## Official name

Daily Turtle

The repository name may differ for technical reasons, but the application should always be presented as "Daily Turtle".

---

# Art Style

- Pixel art.
- Fine pixel art rather than large blocky pixels.
- Keep the pixel aesthetic clearly visible.
- Cozy and welcoming atmosphere.
- Simple, readable visuals.

---

# Mascot

The turtle is the project's mascot.

It should appear throughout the application to reinforce the project's identity.

---

# User Interface

The interface should remain:

- clean;
- readable;
- lightweight;
- calm;
- easy to understand.

Avoid unnecessary visual clutter.

---

# Layout Structure

- The app's content lives inside a single framed "page" surface on a flat background, rather than a stack of separately boxed cards.
- Material Design is used as a *structural* inspiration only — elevation, one defined surface — not a visual theme change.
- The parchment/RPG identity described above remains the actual visual theme; Material only informs how content is framed.
- Sections within the page stay lightly separated (dividers, thin accents) rather than individually boxed/elevated.

---

# Quest Cards

Quest cards should resemble:

- old parchment;
- adventure journals;
- fantasy quest logs.

The inspiration comes from RPG quest books rather than modern productivity apps.

---

# Future additions

This document is expected to evolve as new design decisions are made.
